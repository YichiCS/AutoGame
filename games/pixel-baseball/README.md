# 像素甲子园：监督之路

一个以日本高中棒球为题材的**像素风挂机经营游戏**。你是一所高中棒球部的监督：球队每天按你定下的方针自己训练、比赛日自动排出阵容自动比赛，你要做的是定方针、修设施、在关键时刻拿主意——带着这支队伍一路打进甲子园。

### 👉 [点这里直接在浏览器里玩](https://yichics.github.io/AutoGame/games/pixel-baseball/dist/)

> 本游戏收录在 [AutoGame 像素游戏厅](https://yichics.github.io/AutoGame/)（原仓库 [YichiCS/Pixel-Baseball](https://github.com/YichiCS/Pixel-Baseball)）。更新规则见仓库根目录的 `CONTRIBUTING.md`，版本记录见 [CHANGELOG.md](CHANGELOG.md)。

## 怎么玩

- **时间自动流逝**：1 倍速下游戏里的一天约 1.5 秒；空格暂停 / 继续，数字键 1～4 切换 1x / 2x / 4x / 10x。需要你决定的事出现时会自动暂停。
- **关掉页面也在练**：读档时会补上离开期间的训练（最多 120 天，遇到要你决定的事会停下），可以在设置里关闭。
- **方针**：训练方针（均衡 / 打击 / 投手 / 守备走垒 / 体能 / 精神 / 实战）、训练强度、疲劳过高自动休养、学业、比赛风格、投手起用（王牌主义 / 轮换 / 继投）、起用方针、招生方针。
- **设施**：用部费修建和升级球场、打击笼、投球练习场、力量训练室、室内练习场、医务室、影像分析室、宿舍，每样 5 级，修好后会出现在练习场画面里。
- **托管**：12 类事件可以分别交给托管（按推荐选项处理），也可以一键「全部问我 / 小事托管 / 全部托管」。
- **观战**：重要的比赛（甲子园、神宫、选拔、县大会八强以后）会在画面里一球一球地进行，随时可以跳过；也可以设成全部观战或不观战。
- **存档**：每 15 秒自动保存在浏览器本地。右上角「⚙ 设置」可以导出 / 导入；在游戏厅的「存档中心」可以和其他游戏的存档一起备份。
- 屏幕左边缘的小标签：返回游戏厅、跳到存档管理（可上下拖动）。

## 游戏内容

### 一年的流程
4 月新生入部 → 春季县大会（→ 春季地区大会）→ 6 月梅雨、期末考试 → **7 月夏季县大会**（冠军去 **8 月甲子园**）→ 夏天结束三年级引退、任命主将、校方评价 → 秋季县大会 → 秋季地区大会（冠军去**明治神宫大会**，成绩好的 1 月入选**春季选拔**）→ 10 月职业选秀会议 → 冬训（12～3 月禁止对外比赛）→ 3 月毕业典礼、春季选拔。每周六有练习赛，偶尔会有名门的招待赛。

### 球员
- 15 项能力（击球、力量、选球眼、跑速、肩力、守备、捕球、触击、跑垒、球速、控球、耐力、球威、精神、体质），每项都有隐藏的能力上限；弹道 1～4；9 个守备位置的适性。
- 潜力、成长型（早熟 / 普通 / 晚成）、9 种性格、练习态度、调子（5 档）、疲劳、干劲、信赖、学力、人气、伤病（重伤可能留下后遗症）。
- 49 种特殊能力（关键时刻○、对危机○、夺三振、激光肩、配球高手、大舞台○、变化球锋利、投球组合○、速球派、铁腕、怪物……），都在比赛和育成中实际生效。
- 训练得到五种经验（力量 / 敏捷 / 技术 / 变化 / 精神），按每个人的「培养方针」自动加点。
- 「慧眼」够高（或影像分析室等级够高）才能看到潜力和能力上限。

### 变化球（21 种）
| 系列 | 球种 |
| --- | --- |
| 直球系 | 二缝线、卡特球、伸卡球、内飘球 |
| 横向 | 滑球、高速滑球、横扫球、纵向滑球 |
| 纵向下坠 | 曲球、慢速曲球、指关节曲球、强力曲球、指叉球、快速指叉球 |
| 变速 | 变速球、圈指变速球、掌心球 |
| 反向 | 下沉球、螺旋球 |
| 特殊 | 蝴蝶球、陀螺球（传说级，只能靠特殊机缘） |

每种球的球速比例、挥空率、滚地倾向、控球难度、暴投风险、对同侧 / 异侧打者的效果和变化方向都不同。投手最多掌握 6 种（看潜力），等级 1～7；投球姿势（上手 / 四分之三 / 侧投 / 下勾）和已经会的球种决定新球种学得快不快。变化球练到高等级后，有机会开发出独创的**魔球**。

### 事件（90 多种）
70 多种随机事件：低潮、手感火热、恋爱、开窍、自主夜练、骄傲自满、测速枪、黑眼圈、偷偷打工、家里的变故、转学的念头、肘部的异样、想提前复出、酷暑、水泡、腰痛、媒体批评、灵光一闪、想学新球种、魔球、新的握法、改侧投、转守位、二刀流、改左打、神秘的老人、录像研究会、最后的夏天、霸凌传闻、队内气氛、争执、主将的压力、连胜的秘密、新战术、不祥事、职业 OB 回校、OB 会长的请求、祭典、文化祭、家长投诉、考试危机、媒体追捧、吹奏乐部、小球迷的来信、修学旅行、运动会、球场的猫、宿敌的挑衅、可疑的人影、招待赛、梅雨、台风、大雪、纪录片、赞助、可疑的赞助、OB 的礼物、器材老化、有前途的中学生、「怪物」中学生、转学生……还有新生入部、主将任命、重伤、选秀会议、毕业、年度总结、监督升级、其他学校的邀请等 20 来种系统事件。每件事都有推荐选项，可以按类别交给托管。

### 监督生涯
5 种出身、8 项监督能力（升级时自己选）、名声（无名 → 传说）、校方每年的目标与评价、其他学校的邀请（跳槽）、解任、27 项成就、职业 OB 的后续发展。

## 发布

本游戏随 AutoGame 一起发布：GitHub Pages 直接发布 AutoGame 仓库 main 分支的根目录，**不会替你构建**，所以修改源码后要运行 `npm run build`，把新的 `dist/index.html` 一起提交。AutoGame 的检查（`node scripts/check.mjs --build`，GitHub Actions 每次推送都会跑）会重新构建并确认提交的 `dist/index.html` 是最新的。更新流程见仓库根目录的 `CONTRIBUTING.md`（分支名 `pixel-baseball-v<版本号>`）。

构建结果是一个资源全部内联的 HTML 文件，末尾引入游戏厅的悬浮标签 `../../../hub/dock.js`；单独拿出来放在任何路径下也能运行（只是没有悬浮标签）。

## 开发

需要 Node.js 20 以上。

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173 ，保存后自动刷新
npm run build      # 生成单文件 dist/index.html
npm run typecheck  # TypeScript 类型检查
```

无界面测试：

```bash
node scripts/run-ts.mjs tests/idle.ts 10 30 7 1 all   # 挂机 10 年（县 id 30 = 鸟取，种子 7，选第 2 所学校，全部托管）
node scripts/run-ts.mjs tests/calib.ts                # 按需生成的对手名单与战力评分是否一致
node scripts/run-ts.mjs tests/balance.ts 42 400       # 比赛引擎统计（打率、三振率、得分……）
node scripts/run-ts.mjs tests/fuzz.ts 1500            # 比赛引擎模糊测试（随机指令 + 不变量检查）
node scripts/run-ts.mjs tests/growth.ts               # 球员成长曲线
```

### 目录结构

```
src/
  core/        游戏逻辑（与界面无关，可在 Node 中运行）
    types.ts      数据结构            state.ts     全局状态、动态、大事记
    calendar.ts   日历（一年 360 天）  sim.ts       每日 tick、年度流程、离线进度
    daily.ts      训练、疲劳、伤病、调子
    season.ts     大会日程与晋级链     tournament.ts 淘汰赛
    matchday.ts   本校比赛：组队、按种子模拟、写回结果
    world.ts      本县学校（存档）、外县学校与对手名单（按种子生成）
    player.ts     球员生成            growth.ts    经验与成长、球种学习
    attrs.ts      能力评价            team.ts      阵容编排与战力
    recruit.ts    招生                draft.ts     选秀与毕业
    economy.ts    部费与设施          career.ts    监督、目标、跳槽、成就
    queue.ts      决策队列与托管      events/      事件（系统 / 球员 / 球队与学校）
    newgame.ts    新游戏              save.ts      存档
  sim/         比赛引擎（match.ts 逐球模拟、ai.ts 战术 AI、quick.ts 快速模拟）
  render/      像素绘图（scene.ts 练习场、field.ts 球场与动画、portrait.ts 头像）
  ui/          Preact 界面（App、Scene 观战、tabs/ 各页、Modals 弹窗、loop.ts 主循环）
  data/        名字、都道府县、特殊能力、球种
tests/         无界面测试
scripts/       构建脚本
assets/fonts/  像素字体
dist/          构建产物（单文件 index.html，要提交）
docs/          截图
game.json      游戏厅清单：名字、版本、封面、构建命令、存档位置
save-adapter.js 给游戏厅用的存档适配器
CHANGELOG.md   更新日志
```
