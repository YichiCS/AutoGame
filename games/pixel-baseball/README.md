# 像素甲子园：监督之路

一款以日本高中棒球为题材的**像素风经营模拟游戏**。你将以「监督」的身份开始执教生涯：招募新生、制定训练、亲自指挥比赛、经营球队财务、应对各种突发事件——目标是站上甲子园的舞台。名声提升后，名门学校会向你抛出橄榄枝，你也可以选择跳槽，书写属于自己的监督传奇。

### 👉 [点这里直接在浏览器里玩](https://yichics.github.io/AutoGame/games/pixel-baseball/dist/)

> 本游戏收录在 [AutoGame 像素游戏厅](https://yichics.github.io/AutoGame/)（原仓库 [YichiCS/Pixel-Baseball](https://github.com/YichiCS/Pixel-Baseball)）。更新规则见仓库根目录的 `CONTRIBUTING.md`，版本记录见 [CHANGELOG.md](CHANGELOG.md)。

## 快速开始

在线游玩：<https://yichics.github.io/AutoGame/games/pixel-baseball/dist/>，也可以从 [游戏厅首页](https://yichics.github.io/AutoGame/) 进入。离线游玩：直接用浏览器打开 **`dist/index.html`**（单文件，无需安装任何东西）。

- 电脑：推荐最新版 Chrome / Edge / Firefox，窗口宽度 1280 以上。
- 手机 / 平板：支持竖屏和横屏。竖屏时导航栏在屏幕底部（可左右滑动），比赛中「下一球 / 下一打席 / 自动」按钮固定在屏幕底部；宽表格可以左右滑动查看。
- 存档保存在浏览器本地（IndexedDB），每周结束时自动存档，也可以在「系统」页面导出 / 导入存档文件。游戏厅的「存档中心」可以把全部栏位（和其他游戏的存档一起）导出 / 导入。
- 屏幕左边缘的小标签：返回游戏厅、跳到存档管理（可上下拖动）。
- 界面缩放可在「系统 → 设定」中调整（像素字体在 100% / 200% 时最清晰）。

## 新手入门

1. **选起点**：初期名声低，只有弱校会邀请你。学校少的县（如鸟取、福井、高知）夏季只需 4 胜就能进甲子园，适合第一次游玩。
2. **看首页的「待办与提示」**：教练空缺、赞助提案、可以家访的中学生、疲劳过度的球员……都会列在这里，点一下就能跳转。
3. **先补教练**：投手 / 打击 / 守备教练直接提升训练效率，训练师降低伤病。部费不多时可以先招能力一般、年薪便宜的。
4. **训练**：前期用「均衡」预设 + 「普通」强度即可；冬季（12~2 月）多练体能。疲劳超过 60 就该休养了。
5. **招募**：4 月到次年 2 月，每周把行动力用在家访上，盯住评价高、竞争对手意向不高的中学生。
6. **比赛**：县大会前几轮可以「快速结束」；关键比赛「亲自指挥」——空格键推进一个打席，Enter 推进一球。注意一周 500 球的限制，大会密集周提前安排好投手轮换。
7. **经营**：资金宽裕时优先扩建投球练习场、打击笼与球场；有了成绩再考虑宿舍（私立）与室内练习场。

## 游戏内容

### 监督生涯
- 5 种出身（前职业球员、前甲子园英雄、体育教师、数据分析师、企业家），决定初始能力与名声。
- 从全国 47 个都道府县中选择起点，三所学校向你发出邀请（公立 / 私立，强弱各异）。
- 8 项监督能力（打击/投手/守备指导、战术指挥、统率力、招募口才、交涉力、慧眼），比赛与育成积累经验升级加点。
- 校方每年设定目标，夏季结束时评价；私立学校成绩太差会被解任，合同到期由满意度决定是否续约。
- 名声提升后会收到其他学校（包括外县）的邀请，在转任窗口期可以**跳槽**，原学校的球员与教练会留下。
- 16 项成就、执教履历、OB 名鉴（含职业球员的后续发展）。

### 球员与育成
- 15 项能力（击球、力量、选球眼、跑速、肩力、守备、捕球、触击、跑垒、球速、控球、耐力、球威、精神、体质）+ 7 种变化球（等级 1~7）+ 弹道 + 9 个守位的适性。
- 40 多种特殊能力（关键时刻○、对危机○、夺三振、激光肩、配球高手、大舞台○、怯场、怪物……），每一种都会在比赛或育成中实际生效。
- 隐藏的潜力上限、成长型（早熟 / 普通 / 晚成）、9 种性格、练习态度；监督的「慧眼」决定你能看到多少。
- 训练获得五种经验（力量 / 敏捷 / 技术 / 变化 / 精神），按培养方针自动加点，也可以手动加点、学习特殊能力、克服负面特性。
- 9 种练习菜单自由配比 + 4 档强度、个别练习（重点能力 / 新变化球 / 守位转换）、合宿、冬训、梅雨、期末考试与补习。
- 疲劳、调子（5 档）、干劲、信赖、伤病（含重伤后遗症）、学力、人气、团队默契、战术熟练度。

### 比赛
- 逐球模拟引擎：投球位置与球种、挥棒判断、击球质量、滚地 / 平飞 / 高飞 / 内野高飞、守备范围与失误、跑者推进、双杀、高飞牺牲打、暴投、不死三振……
- 现场指挥：自由打击、积极、待球、轻打、强振、牺牲触击、触击安打、抢分触击、打带跑、盗垒、双盗垒、狙球（猜直球 / 变化球）；配球（指定下一球的球种与位置）、投球方针（力投 / 诱打 / 慎重）、守备阵型（前进守备 / 双杀阵型 / 防长打 / 触击防备）、申告敬远、外角吊球、牵制、传令（每场 3 次）、代打、代跑、换投、守备替换。
- 高中棒球规则：一周 500 球用球数限制、10 局起抢分决胜（无人出局一二垒）、提前结束规则（5 局 10 分 / 7 局 7 分）、可选 DH 制。
- 像素球场动画（甲子园有黑土内野、常春藤外墙、阿尔卑斯应援席）、计分板、实况解说、好球带示意、8-bit 音效（还有比赛开始的警笛）。
- 也可以选择观战（AI 指挥，可随时接管）或快速结束。

### 大会
春季县大会 → 春季地区大会 → 夏季县大会 → **夏季甲子园**（49 校）→ 秋季县大会 → 秋季地区大会 → 明治神宫大会 → **春季选拔**（32 校，含 21 世纪枠与神宫枠）。另有练习赛、招待赛、10 月的职业选秀会议。东京与北海道的夏季大会分为两个地区。

### 招募
- 每年一届中学生：情报迷雾（视察提升情报等级）、知名度、与其他学校的意向竞争、邀请参观、监督家访、特待生名额。
- 一般入部生（偶有璞玉）、入部方针、转学挖角（转学生一年内不能出场公式战，且有丑闻风险）。

### 经营
- 部费收支：学校拨款、OB 会捐款、后援会、赞助、甲子园募款；教练薪水、用具、伙食、远征、设施维护、奖学金、医疗。
- 8 种设施（球场、室内练习场、力量训练室、投球练习场、打击笼、宿舍、医务室、影像分析室），扩建需要工期。
- 教练团队 7 种职务（投手 / 打击 / 守备走垒教练、体能训练师、球探、数据分析员、部长），可从市场招聘或从其他学校**挖角**，也可能被别人挖走。
- 赞助与代言：球具合约、地方企业、媒体合作、监督本人的广告代言、饮料冠名……以及违反学生棒球宪章的「灰色交易」。

### 随机事件
40 多种带选项的事件：投手肘部异样、霸凌传闻、OB 会长的请求、电视台纪录片、酷暑、低潮、恋爱、转学念头、职业球探来访、台风、职业 OB 回校指导、球员开窍、自主夜练、伤员想提前复出、大雪、球探发现的原石、媒体批评投手过度使用、宿敌的挑衅、文化祭、不祥事、教练被挖角、新年参拜、甲子园之土……

## 发布

本游戏随 AutoGame 一起发布：GitHub Pages 直接发布 AutoGame 仓库 main 分支的根目录，**不会替你构建**，所以修改源码后要运行 `npm run build`，把新的 `dist/index.html` 一起提交。AutoGame 的检查（`node scripts/check.mjs --build`，GitHub Actions 每次推送都会跑）会重新构建并确认提交的 `dist/index.html` 是最新的。更新流程见仓库根目录的 `CONTRIBUTING.md`（分支名 `pixel-baseball-v<版本号>`）。

注意事项：

- 构建结果是一个资源全部内联的 HTML 文件，末尾引入游戏厅的悬浮标签 `../../../hub/dock.js`；单独拿出来放在任何路径下也能运行（只是没有悬浮标签）。
- 存档跟着「浏览器 + 网址的域名」走：yichics.github.io 上的存档与本地打开 `dist/index.html` 的存档互不相通，换设备或换浏览器也看不到之前的存档。需要转移时用游戏厅的「存档中心」或游戏内「系统 → 导出存档 / 导入存档」。
- iOS：可以在 Safari 中「分享 → 添加到主屏幕」，以全屏方式游玩。从主屏幕打开与在 Safari 中打开是两份独立的存档；Safari 对长时间未访问的网站可能会清除本地数据，建议定期导出存档备份。

## 开发

需要 Node.js 20 以上。

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173 ，保存后自动刷新
npm run build      # 生成单文件 dist/index.html
npm run typecheck  # TypeScript 类型检查
```

无界面测试（用于平衡性调整与回归测试）：

```bash
node scripts/run-ts.mjs tests/balance.ts 42 400   # 比赛引擎统计（打率、三振率、得分……）
node scripts/run-ts.mjs tests/growth.ts           # 球员成长曲线
node scripts/run-ts.mjs tests/season.ts 3         # 自动推进 3 年
node scripts/run-ts.mjs tests/career.ts 10        # 会经营的机器人监督，10 年生涯（含跳槽、存读档）
node scripts/run-ts.mjs tests/fuzz.ts 1500        # 比赛引擎模糊测试（随机指令 + 不变量检查）
```

### 目录结构

```
src/
  core/        游戏逻辑（与界面无关，可在 Node 中运行）
    types.ts      数据结构
    game.ts       每周流程、大会日程、新年度、选拔、比赛结算
    player.ts     球员生成        growth.ts   经验与成长
    attrs.ts      能力评价        team.ts     阵容编排与战力
    training.ts   训练 / 疲劳 / 伤病 / 设施定义
    tournament.ts 淘汰赛          matchday.ts 比赛组队与成绩写入
    world.ts      学校与名单（远方学校按需具象化）
    recruit.ts    招募            staff.ts    教练
    finance.ts    经营与赞助      career.ts   监督生涯、跳槽、成就
    events.ts     随机事件        draft.ts    选秀与 OB
    save.ts       存档            newgame.ts  新游戏
  sim/         比赛引擎（match.ts 逐球模拟、ai.ts 战术 AI、quick.ts 快速模拟）
  render/      像素绘图（球场与动画、程序生成头像）
  ui/          Preact 界面（screens/ 各页面、flow.tsx 推进流程、MatchScreen 比赛画面）
  data/        名字、都道府县、特殊能力与球种数据
tests/         无界面测试脚本
scripts/       构建脚本
assets/fonts/  像素字体
dist/          构建产物（单文件 index.html，要提交）
docs/          截图
game.json      游戏厅清单：名字、版本、封面、构建命令、存档位置
save-adapter.js 给游戏厅用的存档适配器（在游戏厅里显示各栏位的学校和日期）
CHANGELOG.md   更新日志
```
