# 像素甲子园 · 更新日志

每次更新在 `pixel-baseball-v<版本号>` 分支上完成，合并回 main 后上线。新版本写在最上面。

## v2.0.0 — 2026-10-18

**比赛改为以打席为单位亲自指挥。** 平时仍是挂机：时间流逝，球队按方针训练、成长；比赛日打开单独的比赛画面，由你下指令，结果由球员能力和一点运气决定。v1 的存档可以直接继续。

- 比赛画面：进攻时从打者（捕手）身后看，防守时从投手身后看；投手抬腿、跨步、出手，打者引棒、跨步、挥棒、触击都有分解动作。球按球种和等级在本垒前「晚变」，测速显示球速和球种，好球带上标出这个打席每一球的落点；打出去的球切到俯视球场，看球路、守备和跑垒。
- 进攻指令（每个打席一个）：打法（普通、强振、轻打、积极、选球、牺牲触击、触击安打、抢分）、狙球种（直球 / 变化球）、狙路线（内角、外角、高、低）、跑垒积极度（稳健 / 普通 / 积极）、跑者指示（盗垒、打带跑、双盗），以及代打、代跑。
- 防守指令：配球比重（交给捕手 / 直球为主 / 变化球为主）、决胜球、攻击区域、投球方针（普通、全力、抢好球数、慎重、敬远）、守备阵型（前进守备、防双杀、长打防守、防触击）、注意跑者、外角吊球、牵制（每个打席最多 3 次），以及换投、守备替换。
- 对手会参考之前的打席调整策略：上个打席被打中直球就多投变化球、被打中内角就改攻外角、用某个球三振了你就再用它决胜；打者被滑球三振过就会等变化球，看出你今天直球多就狙直球，看穿你两好球后的决胜球就专等它。同一场里第几次面对同一个投手、同一球种连投，都会影响结果。
- 情报与教练：慧眼和影像分析室决定能不能看穿对方这个打席的打算；教练会根据看得到的情报给出建议，可以一键采用。
- 打席自动化：每个打席都亲自指挥 / 关键时刻才问我 / 只指挥进攻 / 只指挥防守 / 全部交给教练，比赛中随时切换；还有「本局交给教练」「交给教练打完」。在「方针」里设定哪些比赛要亲自指挥（默认正式比赛）。
- 开赛前确认今天的打线、指定先发投手；赛后看比分、MVP 和每个人的成绩。比赛进行中关掉页面，下次打开会从同一个打席继续（按记录重演，结果一模一样）。
- 新增「阵容」页：自己排 9 棒的人和守位、先发顺位、下一场先发；受伤、停赛的人比赛当天自动补位并说明。练习赛默认仍按起用方针自动排，也可以设成同样用这套阵容。
- 能力一律用 0-100 的数字显示（球速另附 km/h），按档位上色；球员列表和详情里标出最近两周涨了多少。
- 引擎：投球的位置区分内角 / 外角 / 高 / 低（低球多滚地、高的快速直球容易挥空、内角容易塞住打者、外角容易推打）；跑垒积极度影响多抢一个垒和高飞回垒冲本垒；注意跑者降低盗垒成功率；AI 投手会牵制快腿跑者。
- 去掉 v1 的「观战」模式（被比赛画面取代）。
- 新增测试 `tests/live.ts`：随机下指令打完整场，再按记录重演（包括中途读档），结果必须一模一样。

## v1.0.0 — 2026-10-18

**全面改版为挂机游戏**（参照科研模拟器）。旧版（经营版）的存档无法在新版里继续，可以在游戏厅「存档中心」导出备份或清除。

- 挂机主循环：时间按天自动流逝（1 / 2 / 4 / 10 倍速，空格暂停），球队每天按方针训练、比赛日自动排阵自动比赛；需要拿主意的事出现时自动暂停；关掉页面期间有离线进度（最多 120 天）。
- 经营大幅简化：去掉行动力、每周手动推进、逐球指挥、训练菜单配比、家访、教练市场、赞助合同；改成十来项「方针」（训练方针、强度、学业、比赛风格、投手起用、起用方针、招生方针）和「部费 + 8 种设施」。
- 保留完整的球员数值：15 项能力与能力上限、弹道、潜力、早熟 / 晚成、9 种性格、调子、疲劳、干劲、信赖、伤病（重伤可能留下后遗症）、学力、49 种特殊能力；按「培养方针」自动加点。比赛仍由逐球引擎模拟，数值真实起作用。
- 球种扩充到 21 种：二缝线、卡特、伸卡、内飘、滑球、高速滑球、横扫球、纵向滑球、曲球、慢速曲球、指关节曲球、强力曲球、指叉、快速指叉、变速、圈指变速、掌心球、下沉球、螺旋球、蝴蝶球、陀螺球，各有球速、挥空、滚地、控球难度、暴投风险和方向；投球姿势与已会的球种决定能学什么。变化球表按方向排开，新增「魔球」（独创球种）和「变化球锋利」「投球组合○」「速球派」「铁腕」等特殊能力。
- 事件扩充到 90 多种，其中随机事件 70 多种（低潮、恋爱、开窍、夜练、骄傲自满、测速枪、学新球种、改侧投、转守位、二刀流、神秘的老人、修学旅行、文化祭、宿敌、不祥事、赞助、OB 回校……），每件都有推荐选项，可以按 12 个类别托管。
- 赛程：春季县大会、地区大会、夏季县大会 → 甲子园、秋季县大会 → 地区大会 → 明治神宫大会 / 春季选拔，每周六练习赛；夏天结束三年级引退、主将任命、选秀会议、毕业、年度总结。
- 观战：重要比赛在画面里一球一球地进行（记分板、实况），可以随时跳过；也可以设为全部观战或不观战。
- 像素练习场画面：球员按当天的训练在打击笼、牛棚、内野、外野跑道、重训室前活动，设施修好后会出现在画面里，天色跟随现实时间，季节和天气跟随游戏日期。
- 监督生涯：名声、等级与能力成长、校方年度目标与评价、其他学校的邀请（跳槽）、解任、27 项成就、职业 OB 的后续发展。
- 存档改为 localStorage（`pixel-baseball:save`），体积小；游戏厅存档适配器同时显示新存档和旧版存档。
- 新增无界面测试 `tests/idle.ts`（托管跑 N 年，打印平衡统计）与 `tests/calib.ts`（对手名单战力校准）。
