## v2.2.0 — 2026-10-18

**比赛改成一球一球地指挥，球员有了总评、谁都能守任何位置，画面和手机界面重做。** 旧存档可以直接继续（读档时自动迁移；比赛打到一半的存档会从开赛前重新开始）。

比赛：
- **一球一球地指挥**：画面中间是放大的瞄准网格——11×11 格，中间 9×9 是好球带，外面一圈是坏球区；格子里的数字是这名打者在九宫格每一格的打击率（红的是热区）。
- **投球**：选球种（每个球种显示这一球的质量 0-100，直球看球速、球威、控球，变化球看等级和球威，累了会下降），在网格上点要投的位置（再点一次直接投），网格上会显示这一球大概落在哪。实际落点按控球、球种质量和体力在目标附近随机散布：直球是圆圆的一团；变化球顺着变化方向拉长、偏向变化的一侧，还可能失投（没变化、留在好打的位置）；蝴蝶球乱飘；偶尔谁都会投歪。
- **离垒警告与牵制**：对方跑者离垒很大时提示（也可能是虚张声势）。牵制成功率看投手的牵制能力（控球、守备、肩力、沉着，左投手、「牵制○」「快速投球」加分）、离垒大小、跑者是不是本来就想跑；每个打席最多 3 次。
- **打击**：每一球之前看到投手这一球打算投哪里的热区图（可能有好几处，投手也在和你猜），点要打的一格——球来到那一格附近就挥棒，离得越近越容易打中、打得越扎实，别处的球放过（两好球后好球带里的球会勉强碰一碰）；也可以不挥棒。各垒跑者可以提前跑：没打中就是盗垒，打中了多跑一个垒，但对方投手看穿了会牵制。
- 打法、狙球种、狙路线、跑垒积极度、配球比重、决胜球、攻击区域、投球方针、守备阵型、注意跑者、外角吊球、教练建议都去掉了——每一球的这几个选择就够了。保留换人（代打、代跑、换投、守备替换）、自动指挥（每一球 / 关键时刻 / 只进攻 / 只防守 / 全部交给教练）、这个半局交给教练、直接打完整场、演出速度。
- AI：投手按球数、打者的冷热区、自己各球种的质量和之前的打席定下每一球的打算（1～3 个目标）；打者看着投手的打算选格子，选球眼越好挑得越准。校准后打率、三振率、挥空率、强弱队胜率和旧版相近（tests/balance.ts、tests/mismatch.ts）。
- 比赛打到一半关掉页面，下次从同一球继续（每一球的指令都记下来，按记录重演；tests/live.ts）。

画面：
- **长焦机位**：打击时从捕手背后看、投球时从投手背后看，投手、打者、捕手被「压」在一起；画面改成方形，网格画在所有人上面，热区和打击率不会被挡住。
- **观众**改成压暗的灰蓝色（甲子园的阿尔卑斯看台用两队的颜色，也压暗）；俯视球场的观众也一样。
- **球员造型重画**：有体积的身体（肩、腰、四肢粗细）、三四层明暗、球衣细节（袖子和滚边、背号、胸前字样、腰带、条纹袜子、钉鞋）、带反光和护耳的打击头盔、捕手护具、主审；脸部在大尺寸时有眼睛眉毛，小尺寸自动简化。人物不动时缓存，画得也更快。

球员：
- **总评与位置**：每个人在 9 个位置上都有一个评价（投手看投球，其他位置看打击和这个位置的守备，左投守捕手和二三游吃亏），评价最高的位置就是最适合的位置，那个评价就是总评。谁都能守任何位置、谁都能投（去掉了「守备适性」）。
- 投手型和野手型只是能力偏向，所有能力都围绕同一个素质：野手的投球能力不再是 15 左右、上限 45 的断层，野手型也可能会一种变化球；训练时新经验的两成留给「另一边」（投手练打击守备、野手练投球）。能力变了，最适合的位置会跟着变（投手和野手之间要明显更合适才换）。
- 培养方针谁都可以选投手方向或打击方向。
- 「偷偷练投球」事件改成提升投球能力；「转换守备位置」改成「加练某个位置」（提升那个位置看重的能力）。
- 旧存档：野手的投球能力按他的打击守备水平补到正常（只升不降），按能力重新判断位置（tests/migrate.ts）。

界面：
- **手机上不用上下滚动就能完成操作**：顶部固定一条（学校、日期、暂停 / 速度、? ⚙），底部固定 7 个页签，只有中间滚动；练习场画面和球队动态放在「概览」最上面；所有弹窗改成从下面弹出的抽屉，选项和按钮固定在底部；开始画面的主按钮固定在底部。按钮至少 40 像素高，不会横向滚动。比赛画面一屏操作：上面比分，中间画面和网格，这一球的选择和开始按钮贴在底部；有跑者、球种多时画面自动缩小一点，连 iPhone SE 那样的小屏、或者浏览器地址栏占掉一截高度时也不用滚动；手机上跑者一个垒一格，整格就是牵制 / 提前跑按钮。
- **上下对齐**：所有列表改成固定列宽、数字右对齐（球员名单、能力、阵容、先发顺位、开赛前的打线和先发投手、换人、赛后成绩、设施、收支、比赛与对阵表、日程、OB、成就、大事记），名单和阵容有表头。
- **不再出现任何推荐**：事件选项不再标「推荐」，开赛前的先发投手不再标「推荐」，比赛里的「教练建议」去掉，主将任命不再附最合适人选的卡片，监督升级的选项按固定顺序列出（托管照旧按原来的选项处理）。
- **事件选项标出可能的结果**：每个选项下面列出会发生什么——部费、干劲、疲劳、能力、受伤的概率和天数、球迷、校方……（在存档副本上模拟几十次算出来，不影响游戏；tests/preview.ts）。原来手写的提示也保留。
- **看得懂的数值**：疲劳、干劲显示成「疲劳 23」这样的数字（按程度变色），不再是没有说明的绿条；概览的战力、满意度、默契、监督经验等条旁边都有数字。
- 名单按总评排、大号显示；球员详情显示总评和 9 个位置的评价；球种在名单和详情里显示质量（0-100），圆点是练习等级。阵容里任何人都可以排任何守位、进先发顺位、被指定先发，候选按那个位置的评价排序。
- 设置：从游戏厅打开时有「◀ 返回游戏厅」「存档管理」，离开前自动存档（游戏厅 v1.2.0 去掉了游戏里的悬浮标签）。

## v2.1.0 — 2026-10-18（原 v2.0.0）

**比赛改为以打席为单位亲自指挥。** 平时仍是挂机：时间流逝，球队按方针训练、成长；比赛日打开单独的比赛画面，由你下指令，结果由球员能力和一点运气决定。v2.0 的存档可以直接继续。

- 比赛画面：进攻时从打者（捕手）身后看，防守时从投手身后看；投手抬腿、跨步、出手，打者引棒、跨步、挥棒、触击都有分解动作。球按球种和等级在本垒前「晚变」，测速显示球速和球种，好球带上标出这个打席每一球的落点；打出去的球切到俯视球场，看球路、守备和跑垒。
- 进攻指令（每个打席一个）：打法（普通、强振、轻打、积极、选球、牺牲触击、触击安打、抢分）、狙球种（直球 / 变化球）、狙路线（内角、外角、高、低）、跑垒积极度（稳健 / 普通 / 积极）、跑者指示（盗垒、打带跑、双盗），以及代打、代跑。
- 防守指令：配球比重（交给捕手 / 直球为主 / 变化球为主）、决胜球、攻击区域、投球方针（普通、全力、抢好球数、慎重、敬远）、守备阵型（前进守备、防双杀、长打防守、防触击）、注意跑者、外角吊球、牵制（每个打席最多 3 次），以及换投、守备替换。
- 对手会参考之前的打席调整策略：上个打席被打中直球就多投变化球、被打中内角就改攻外角、用某个球三振了你就再用它决胜；打者被滑球三振过就会等变化球，看出你今天直球多就狙直球，看穿你两好球后的决胜球就专等它。同一场里第几次面对同一个投手、同一球种连投，都会影响结果。
- 情报与教练：慧眼和影像分析室决定能不能看穿对方这个打席的打算；教练会根据看得到的情报给出建议，可以一键采用。
- 打席自动化：每个打席都亲自指挥 / 关键时刻才问我 / 只指挥进攻 / 只指挥防守 / 全部交给教练，比赛中随时切换；还有「本局交给教练」「交给教练打完」。在「方针」里设定哪些比赛要亲自指挥（默认正式比赛）。
- 开赛前确认今天的打线、指定先发投手；赛后看比分、MVP 和每个人的成绩。比赛进行中关掉页面，下次打开会从同一个打席继续（按记录重演，结果一模一样）。
- 新增「阵容」页：自己排 9 棒的人和守位、先发顺位、下一场先发；受伤、停赛的人比赛当天自动补位并说明。练习赛默认仍按起用方针自动排，也可以设成同样用这套阵容。
- 能力一律用 0-100 的数字显示（球速另附 km/h），按档位上色；球员列表和详情里标出最近两周涨了多少。
- 引擎：投球的位置区分内角 / 外角 / 高 / 低（低球多滚地、高的快速直球容易挥空、内角容易塞住打者、外角容易推打）；跑垒积极度影响多抢一个垒和高飞回垒冲本垒；注意跑者降低盗垒成功率；AI 投手会牵制快腿跑者。
- 去掉 v2.0 的「观战」模式（被比赛画面取代）。
- 新增测试 `tests/live.ts`：随机下指令打完整场，再按记录重演（包括中途读档），结果必须一模一样。

## v2.0.0 — 2026-10-18（原 v1.0.0）

**全面改版为挂机游戏**（参照科研模拟器）。旧版（经营版）的存档无法在新版里继续，可以在游戏厅「存档中心」导出备份或清除。

- 挂机主循环：时间按天自动流逝（1 / 2 / 4 / 10 倍速，空格暂停），球队每天按方针训练、比赛日自动排阵自动比赛；需要拿主意的事出现时自动暂停；关掉页面期间有离线进度（最多 120 天）。
- 经营大幅简化：去掉行动力、每周手动推进、逐球指挥、训练菜单配比、家访、教练市场、赞助合同；改成十来项「方针」（训练方针、强度、学业、比赛风格、投手起用、起用方针、招生方针）和「部费 + 8 种设施」。
- 保留完整的球员数值：15 项能力与能力上限、弹道、潜力、早熟 / 晚成、9 种性格、调子、疲劳、干劲、信赖、伤病（重伤可能留下后遗症）、学力、49 种特殊能力；按「培养方针」自动加点。比赛仍由逐球引擎模拟，数值真实起作用。
- 球种扩充到 21 种：二缝线、卡特、伸卡、内飘、滑球、高速滑球、横扫球、纵向滑球、曲球、慢速曲球、指关节曲球、强力曲球、指叉、快速指叉、变速、圈指变速、掌心球、下沉球、螺旋球、蝴蝶球、陀螺球，各有球速、挥空、滚地、控球难度、暴投风险和方向；投球姿势与已会的球种决定能学什么。变化球表按方向排开，新增「魔球」（独创球种）和「变化球锋利」「投球组合○」「速球派」「铁腕」等特殊能力。
- 事件扩充到 90 多种，其中随机事件 70 多种（低潮、恋爱、开窍、夜练、骄傲自满、测速枪、学新球种、改侧投、转守位、二刀流、神秘的老人、修学旅行、文化祭、宿敌、不祥事、赞助、OB 回校……），每件都有推荐选项，可以按 12 个类别托管。
- 赛程：春季县大会、地区大会、夏季县大会 → 甲子园、秋季县大会 → 地区大会 → 明治神宫大会 / 春季选拔，每周六练习赛；夏天结束三年级引退、主将任命、选秀会议、毕业、年度总结。
- 观战：重要比赛在画面里一球一球地进行（记分板、实况），可以随时跳过；也可以设为全部观战或不观战。
- 像素练习场画面：球员按当天的训练在打击笼、牛棚、内野、外野跑道、重训室前活动，设施修好后会出现在画面里，天色跟随现实时间，季节和天气跟随游戏日期。
- 监督生涯：名声、等级与能力成长、校方年度目标与评价、其他学校的邀请（跳槽）、解任、27 项成就、职业 OB 的后续发展。
- 存档改为 localStorage（`pixel-baseball:save`），体积小；游戏厅存档适配器同时显示新存档和旧版存档。
- 新增无界面测试 `tests/idle.ts`（托管跑 N 年，打印平衡统计）与 `tests/calib.ts`（对手名单战力校准）。
